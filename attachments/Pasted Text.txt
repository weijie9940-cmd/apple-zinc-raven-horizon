用 Three.js（ES Module + importmap 从 CDN 加载）做一个单文件网页 3D 仿真，还原"电动木质滚珠机"的完整工作循环：电机 → 多级齿轮 → 链条提升机把钢珠送回顶部 → 钢珠沿螺旋轨道和 S 形波浪轨道滚下 → 底部回收盘 → 再次被提升，无限循环。外观为浅色木质风格，所有零件程序化建模，不许用外部模型文件。


1. 禁用物理引擎：不得使用 cannon-es / ammo / Rapier / physi.js 等任何刚体物理库。小球运动必须用"轨道参数化 + 确定性积分"，这是根绝穿模和反重力的唯一办法。
2. 小球运动模型：每段轨道是一条参数曲线 r(t), t∈[0,1]，预先按 400 个采样点计算弧长表。球的状态只有两个标量：弧长位置 s 和速度 v。用固定时间步长 dt=1/120 做积分（渲染帧用累加器 accumulator 消化，不许帧率波动影响机构时序）：dv/dt = -g·(dy/ds) − μ·v，其中 dy/ds 由弧长表差分得到（重力沿轨道切向分量），g 取 9.8 乘以场景单位换算系数，μ 取 0.2。球的渲染位置 = 曲线在 s 处的位置 + 轨道法向抬高一个球半径；滚动视觉：球绕"切向 × 世界上向"轴旋转，角速度 ω=v/R。
3. 轨道衔接：球到达一段轨道末端时，按"出口→入口"映射表进入下一段轨道，速度标量 v 继承、运动方向按新轨道切向重建。所有轨道的出口坐标与下一段入口坐标必须引用同一个常量定义，不许在两处手写两遍坐标。
4. 同轨道多球防穿插：同一轨道上的球按 s 排序，后球与前球保持最小间距 2.2R；若后球追上，后球速度钳制为前球速度（简化一维跟随，不做碰撞反弹，不许两球重叠）。
5. 齿轮啮合数学：齿轮几何由函数 gearGeometry(齿数 z, 模数 m, 厚度) 程序化生成，梯形齿近似即可，齿数 z 按真实整数。两啮合齿轮中心距 d=(z1+z2)·m/2，转速比 ω2 = −ω1·z1/z2；初始相位必须让一方齿轮的齿尖对准另一方齿轮的齿槽中央（相位偏移 π/z2），啮合点处齿与齿不许视觉穿插。
6. Three.js 从 CDN 加载，必须写加载失败降级：CDN 不可用时页面显示中文错误文案，不许白屏。


里程碑 M1 —— 底座与动力：木质底座框架（底板 + 4 根立柱 + 顶板，浅色木纹 MeshStandardMaterial，颜色 #d9b98a 附近，roughness 0.8）；黄色减速电机（圆角方块机身 + 输出轴，固定转速，机身 #f5b301）；三级齿轮传动：电机小齿轮(z=12) → 中间齿轮(z=36) → 大齿轮(z=60)，全部竖直安装、轴线互相平行，所有啮合点按红线第 5 条对齐。转起来后肉眼可见啮合、无穿插。
里程碑 M2 —— 轨道与小球：螺旋轨道（半径 1.2、3 整圈、总降深 2.4）；S 形波浪轨道（水平面内正弦曲线，2 个完整波形、振幅 0.8、波长 2.0，叠加纵向缓降总降深 1.2）；直线缓坡连接螺旋出口 → S 弯入口、S 弯出口 → 底部回收盘（全程坡度处处为负，保证球不减速到停）。轨道造型：每条轨道由两根平行圆管构成（TubeGeometry），圆管中心线为轨道曲线沿水平法向 ±0.55R 偏移，管半径 0.12R；球半径 R 架在两管之间滚动。钢珠金属材质（metalness 0.9, roughness 0.25），共 8 颗。先验证"顶部手动放球"：球从螺旋顶端出发能完整滚到回收盘，全程无穿模、无悬空、无卡死。
里程碑 M3 —— 提升机与闭环：链条提升机（竖直平面内闭环链条路径，矩形圆角环，高 3.2），顶部链轮与 M1 的大齿轮同轴联动（角速度按链轮/齿轮齿数比换算）；链条上等距挂 6 个料斗（开口小盒）。料斗经过底部回收盘最低点时"舀"起一颗球（球状态切换为"被提升"，位置锁定到料斗中心）；到顶部释放点时把球倒入螺旋轨道入口（球状态切回"轨道运动"，s=0，v=0.3 初速）。时序约束：料斗到达顶部时若螺旋入口 1.5R 范围内有球（入口占用标志），链条整体暂停半拍再倒球，不许两球在入口重叠。UI：播放/暂停、速度 0.5x/1x/2x、钢珠数量 4/8/12 切换、视角预设（全景 / 俯视 / 齿轮特写）；OrbitControls 拖拽旋转 + 滚轮缩放，默认 45° 俯视全景。


1. 打开页面 3 秒内自动开始运行，无需任何操作。
2. 所有齿轮啮合转动，慢放（0.5x）检查啮合点无齿穿插。
3. 8 颗球无限循环：回收盘→提升→顶部→螺旋→S 弯→回收盘，全程球始终贴在轨道上，无穿模、无飞球、无卡死，连续跑 5 分钟不乱。
4. 暂停/调速/球数切换即时生效，不破坏循环时序。
5. 拖拽旋转、滚轮缩放流畅，默认视角能看到整机。
6. 单个 HTML 文件；断网（CDN 失败）时显示中文错误提示而非白屏。

按 M1 → M2 → M3 顺序实现，每完成一个里程碑先自检该里程碑对应的验收项，通过后再做下一个。不许一次性堆完再调。
